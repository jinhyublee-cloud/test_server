# 하루기록 (DayLog) 2.7-fold6

캘린더, 통화 기록, 문자, 카톡, 이메일, 앱 알림을 한 화면에 모아 보고 하루 요약을 만드는 개인용 안드로이드 앱입니다.
**인터넷 권한이 없는 앱**이라 모든 기록과 요약이 이 폰 안에서만 처리됩니다.

## 화면

| 탭 | 내용 |
|---|---|
| 홈 | 하루 요약 카드, 종류별 개수(일정·문자·전화·카톡·메일·앱), 다음 일정, 챙겨야 할 일, 돈 흐름, 최근 활동 |
| 타임라인 | 주간 날짜 선택, 검색, 종류 필터, 오전/오후/저녁으로 묶은 통합 기록 (같은 카톡방 연속 메시지는 묶음) |
| 요약 | 한 줄 요약, 시간대별 활동 그래프, 하루의 흐름, 많이 연락한 사람, 일정과 돈, 챙겨야 할 일, 내일 미리보기 |
| 설정 | 권한, 보안, 자동 생성 시각, 알림을 모을 앱, 보관 기간, 전체 삭제 |

## 2.7-fold6: 폴드 대응 (갤럭시 Z 폴드6)

버전 번호는 2.7 그대로이고, 앱 정보(설정 → 앱 정보 → 버전)에 "2.7-fold6"으로 표시됩니다.

- 접기·펴기·회전·화면 분할 때 앱 화면을 새로 만들지 않음 → 보던 탭 유지, 잠금이 켜져 있어도 지문을 다시 묻지 않음
- 앱 창 폭이 600dp 이상(펼친 화면)이면 왼쪽 세로 탭 + 가운데 내용(최대 720dp), 좁으면(커버 화면·화면 분할) 아래쪽 탭
- 글자 크기를 키워도 깨지지 않게
  - 시간·날짜 칸이 두 줄로 쪼개지던 문제 (예: "08:0 / 3")
  - 지출·수입 금액이 나란히 안 들어가면 위아래로 쌓음 (예: "+2,350,00 / 0원"으로 쪼개지던 문제)
  - 결제 달력 날짜 칸 높이가 고정이라 금액이 잘리던 문제
- 화면 확인 테스트: `./gradlew testDebugUnitTest` → `app/build/outputs/roborazzi/build/fold/` 에 커버(기본·글자 130%)·펼친 화면(세로·가로) 스크린샷. 결과 예시는 `docs/fold/`

## 2.7에서 바뀐 것 (배포판 점검)

- 첫 실행 개인정보 처리 안내·동의 화면 (본인 폰 사용 확인 포함). 동의 전에는 알림을 저장하지 않음
- 설정 → 앱 정보: 개인정보 처리 안내, 오픈소스 라이선스(Apache 2.0 전문 포함), 버전·서명 인증서 확인
- Android 12(API 31·32) 호환성 수정
  - 앱 시작 시 Android 13 전용 API 호출로 꺼지던 문제
  - 알림 권한 항목이 항상 "꺼짐"으로 보이고 요약·마감 알림이 오지 않던 문제
  - 서명 확인이 키 교체 이전 원래 키를 인식하지 못해 보안 기록에 경고가 남던 문제
- Android Lint: 오류 0건, 보안 분류 경고 0건

## 2.6에서 바뀐 것

- 지출·수입 달력: 챙길 것 → 결제 탭 맨 위 (홈 "돈 흐름" 카드의 "달력에서 날짜별 지출·수입 보기"로도 이동)
  - 날짜 칸마다 그날 지출(-)·수입(+) 금액 (1만 원 이상은 1.7만처럼 짧게), 월 합계
  - 날짜를 누르면 아래에 그날 결제·입금 내역과 합계, ⋮ 메뉴로 합계에서 빼기·다시 넣기, 그날 항목 고르기
  - 이전 달로 이동 가능 (기록 보관 기간보다 오래된 날은 금액이 없을 수 있음)
  - 합계에서 뺀 항목은 달력 금액에도 넣지 않음

## 2.5에서 바뀐 것

- 합계에 넣을 결제·입금 고르기: 체크를 풀면 지출·입금 합계에서 빠짐 (기록은 지우지 않음, 다시 체크하면 복구)
  - 홈 "돈 흐름" → 합계 항목 고르기 (그날), 챙길 것 → 결제 → 합계에 넣을 항목 고르기 (이번 달 결제·입금)
  - 고르는 동안 합계가 바로 바뀌어 보임, 결제/입금 따로 보기
  - 각 줄 ⋮ 메뉴: 합계에서 빼기, "이 곳은 항상 빼기"(내 계좌끼리 이체 등), 다시 넣기
  - 결제 탭 아래 "합계에서 뺀 항목"에서 한꺼번에 확인·되돌리기
- 홈 지출·입금, 결제 탭 월 합계, 카드별 합계, 물어보기 답변, 하루 요약의 지출 모두 같은 기준으로 계산
- 뺀 항목 정보는 HMAC 키 + 암호화로 저장

## 2.4.1에서 고친 것

- 물어보기: "이력·내역·총합·금액·현황·가장" 같은 일반 단어를 가게·사람 이름처럼 검색어로 써서 "기록이 없어요"가 나오던 문제
  - 일반 단어 목록 확대, 기록 어디에도 없는 단어는 검색 조건에서 자동으로 빼고 답함 (뺐다는 안내를 답변 아래에 표시)
  - "가장 많이 쓴 곳", "쓴 곳", "카드값", "사용 내역"을 결제 질문으로 인식, 곳별 합계와 가장 큰 결제 표시

## 2.4에서 바뀐 것

- 물어보기 탭: "어제 어디서 결제했어?", "지난주 금요일 김민수랑 통화했나?", "이번 주 일정", "스타벅스 언제 갔지?" 같은 질문에 답함
  - 질문 해석(기간·주제·검색어) → 암호화된 기록에서 찾기 → 금액·건수는 코드가 계산 → 갤럭시 내장 Gemini Nano(AICore)가 문장만 다듬음
  - AI 문장에 기록에 없는 숫자가 나오면 버리고 기본 답변 사용. AI를 쓸 수 없는 상태면 기본 답변
  - 답변 아래 근거 기록을 누르면 원래 앱·대화방이 열림. 물어본 내용은 저장하지 않고, 앱이 잠기면 지움
  - 설정 → 물어보기에서 기기 AI 사용을 끌 수 있음
- 카톡·문자 항목을 누르면 그 대화방이 바로 열림 (타임라인, 홈, 약속·마감 카드, 물어보기 근거)
  - 알림의 대화방 바로가기를 메모리에만 보관. 폰 재부팅 뒤 아직 새 알림이 없던 방은 카카오톡 앱만 열림
- 앱을 다시 열면(3분 넘게 떠나 있었거나 날짜가 바뀐 경우) 홈의 오늘 대시보드부터 표시, 홈 탭을 누르면 항상 오늘
- 하단 탭: 홈 · 타임라인 · 물어보기 · 챙길 것 · 요약. 설정은 홈 오른쪽 위 톱니바퀴
- 보안: 인터넷 권한은 계속 없음. ML Kit가 넣는 사용 통계 전송 통로(TransportBackendDiscovery)와 네트워크 상태 권한도 제거
- 빌드: Kotlin 2.4.21, ML Kit GenAI Prompt API 1.0.0-beta5

## 2.3에서 고친 것

- 카드 결제 문자
  - "승인번호 12345678"이 있는 카드 문자를 인증번호 문자로 오인해 저장하지 않던 문제
  - "잔여한도"가 있으면 한도 초과로, "할인 330원 적용"이 있으면 광고로 보고 빼던 문제
  - 누적·잔여한도 금액 대신 실제 결제 금액을, 가게 이름과 카드사(9개사 형식 확인)를 함께 기록
  - 카드사·은행·페이 카톡 알림톡 결제도 인식
  - 챙길 것 → 결제 탭에 "이번 달 카드·결제" 목록과 카드사별 합계
- 마감: "11.30(월)까지", "금일까지", "다음 주까지", "월말까지" 인식, 마감마다 "캘린더" 버튼 (종일 일정)
- 행사 공지: 시무식·회식·교육·세미나 등 행사 단어 인식, "일시:/장소:" 형식 공지, 시간 없는 오늘 행사
- "~까지"는 약속이 아니라 마감으로만 분류
- 업데이트하면 최근 35일 기록을 새 규칙으로 다시 분석

## 2.2에서 바뀐 것

- 카톡 약속을 메시지 한 줄이 아니라 같은 방의 이어진 대화(4시간 이내) 단위로 분석
  - 앞 메시지의 날짜("이번 주 토요일 어때?")와 뒤 메시지의 시간·장소("7시에 강남역에서")를 합침
  - 날짜를 못 찾으면 대화한 날로 정하지 않고 "날짜 확인 필요"로 표시 (오늘·이따·퇴근하고 같은 말이 있을 때만 그날)
  - "7시 말고 8시", "토요일 말고 일요일"은 바뀐 쪽을, 저녁 약속의 "8시"는 20시로
  - 같은 요일에 말한 "토요일"이 이미 지났으면 다음 주
  - 과거 이야기("어제 만났던")는 무시, "취소·못 갈 것 같아"는 표시
- 약속·마감·정기 결제를 직접 수정·삭제 (⋮ 메뉴), 삭제한 항목은 "되돌리기" 가능
- 고치거나 삭제한 항목은 이후 다시 분석해도 덮어쓰지 않음
- 업데이트하면 손대지 않은 예전 약속은 지우고 최근 35일 대화를 새 방식으로 다시 분석

## 2.1에서 추가된 것

| 기능 | 내용 |
|---|---|
| 챙길 것 · 약속 | 카톡·문자에서 날짜·시간·장소가 있는 약속 문장을 찾아 카드로 보여줌. "캘린더에 추가"는 삼성 캘린더 입력 화면을 열 뿐, 저장은 사용자가 직접 |
| 챙길 것 · 마감 | "까지·유효기간·만료·마감·D-n" + 날짜가 있는 알림(쿠폰, 회신, 반품 등)을 D-day 순으로. 3일 전·하루 전·당일 오전 9시 알림 |
| 챙길 것 · 정기 결제 | 같은 곳·비슷한 금액(±10%)·비슷한 날짜(±3일)로 두 달 이상 결제되었거나 자동이체 예정 안내가 오면 정기 결제로 표시. 결제 내역은 암호화해 400일 보관 |
| 챙길 것 · 메일 | 메일 알림의 제목·미리보기로 답장 필요/청구·결제/알림/뉴스레터 분류와 두 줄 요약 |

## 설치 (갤럭시 S26 울트라)

1. `DayLog-2.0.apk`를 폰에서 실행합니다. 1.0이 설치되어 있으면 그 위에 업데이트되고, 기존 기록은 자동으로 암호화됩니다.
   - **자동 차단기**가 켜져 있으면 설치가 막힙니다: 설정 → 보안 및 개인정보 보호 → 자동 차단기 → 잠시 끄기.
   - Play 프로텍트 경고가 나오면 "그래도 설치"를 누릅니다.
2. 앱 → **설정** 탭 → "모을 기록"의 항목을 모두 허용합니다.
   - 알림 접근이나 통화 기록이 회색으로 막혀 있으면: 폰 설정 → 애플리케이션 → 하루기록 → ⋮ → **제한된 설정 허용** 후 다시 시도.
3. 삼성 설정 → 배터리 → 백그라운드 사용 한도 → **절전 예외 앱**에 하루기록을 추가하면 수집이 끊기지 않습니다.

## 알아둘 한계

- 요약은 폰 안의 규칙으로 만듭니다(인터넷 AI 사용 안 함). 문장은 단순하지만 사실 위주로 정확합니다.
- 카톡방을 보고 있을 때 온 메시지나 알림을 꺼둔 방은 알림이 없어 기록되지 않습니다.
- 답장 여부는 알 수 없어서 "카톡 답장" 할 일은 직접 체크해 주세요.
